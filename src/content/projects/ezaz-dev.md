The site you're looking at right now. Designed around the "Tactile Digital" philosophy — minimalist, high-craft, and fast.

**Key decisions:**

- Astro 6 with MDX content collections
- Tailwind CSS v4 (CSS-first configuration)
- No animation libraries — pure CSS spring physics
- Web Audio API for haptic-inspired sound cues
- Dual-mode: dimmed light (`#F5F5F7`) + rich dark (`#0E1111`)
