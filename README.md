# Ezaz's Tech Identity

A corner of the internet where I build, write, and document my journey as a software engineer.

This repository powers my personal portfolio and technical blog, focused on software engineering, distributed systems, backend development, web technologies, AI, and everything I'm curious enough to dive into.

## ✨ Features

- Personal portfolio
- Markdown-powered blog
- Responsive design
- Fast static pages with Astro
- SEO-friendly
- RSS feed
- Sitemap
- Newsletter subscription

## 🛠 Tech Stack

- Astro
- TypeScript
- Tailwind CSS
- Markdown
- Astro Content Collections

## 🚀 Getting Started

### Prerequisites

- Node.js 22+
- pnpm

### Installation

```bash
pnpm install
```

### Development

```bash
pnpm dev
```

Open `http: //localhost:4321` in your browser.

## 📦 Available Scripts

| Command             | Description                              |
| ------------------- | ---------------------------------------- |
| `pnpm dev`          | Start the development server             |
| `pnpm build`        | Build the production site                |
| `pnpm preview`      | Preview the production build locally     |
| `pnpm lint`         | Run ESLint                               |
| `pnpm lint:fix`     | Automatically fix ESLint issues          |
| `pnpm format`       | Format the project with Prettier         |
| `pnpm format:check` | Check formatting without modifying files |
